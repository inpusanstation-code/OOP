# 0804 학습 기록

이 저장소는 C++와 Python 기반의 코딩 학습 내용을 정리한 프로젝트입니다. 기본 문법부터 함수, 배열, Windows GUI 프로그래밍, 그리고 Ursa나를 활용한 3D 시각화까지 다양한 예제를 포함하고 있습니다.

## 1. 프로젝트 구성

- Prac/: C++ 학습 프로젝트 폴더
- py_demo/: Python 학습 및 데모 실행 폴더

## 2. C++ 학습 내용

### 2.1 기본 입출력과 함수
- 파일: Prac/Prac/Prac.cpp
- `adder()` 함수를 정의하고, 입력값을 받아 덧셈 결과를 출력하는 기본 예제입니다.
- `cout`, `cin`, 함수 정의, 반환값 처리의 기초를 익혔습니다.

### 2.2 조건문과 함수 활용
- 파일: Prac/Prac/prac6-2.cpp
- 두 정수를 입력받아 더 큰 수를 찾고, 짝수/홀수, 3의 배수 여부를 판별하는 예제입니다.
- `if`, `else`, 삼항 연산자, 함수 분리 방식에 대해 학습했습니다.

### 2.3 배열과 함수
- 파일: Prac/Prac/prac6-3.cpp
- 배열의 합계를 구하고, 배열 요소를 두 배로 바꾸는 예제를 통해 배열과 함수의 관계를 익혔습니다.
- 배열을 인수로 넘기는 방식과 반복문 활용법을 실습했습니다.

### 2.4 Windows GUI 계산기
- 파일: Prac/Prac/Calc.cpp
- Win32 API를 사용하여 윈도우 창과 버튼, 입력창을 만들고 계산기 기능을 구현했습니다.
- 주요 학습 포인트
  - `CreateWindow()`를 이용한 UI 생성
  - `WM_CREATE`, `WM_COMMAND`, `WM_DESTROY` 메시지 처리
  - 버튼 클릭 이벤트를 통한 상태 관리
  - 문자열과 숫자 변환, 예외 처리

### 2.5 도서관 관리 시스템
- 파일: Prac/Prac/LIbrary_commented.cpp
- Win32 API 기반의 GUI 도서관 관리 프로그램으로, 도서 등록, 삭제, 대출/반납, 파일 저장 기능을 구현했습니다.
- 주요 학습 포인트
  - 객체지향 프로그래밍(OOP): `Book`, `BookManager` 클래스 설계
  - Win32 API: 윈도우 생성 및 이벤트 처리
  - 파일 입출력: CSV 형식으로 데이터 저장 및 불러오기
  - UTF-8/UTF-16 문자열 변환을 통한 한글 입력 처리
  - ListView를 이용한 도서 목록 표시 및 선택 기능

## 3. Python 학습 내용

### 3.1 Ursa나 기반 3D 데모
- 파일: py_demo/ursina_demo.py
- Ursa나 엔진을 사용해 회전하는 3D 큐브를 만들고, 마우스 클릭 이벤트로 색상을 변경하는 예제입니다.
- 주요 학습 포인트
  - `Entity`를 이용한 3D 오브젝트 생성
  - `update()` 함수로 애니메이션 처리
  - `input()` 함수로 마우스 이벤트 처리
  - 색상 변경과 텍스트 표시

## 4. 학습 목표

이번 학습을 통해 다음 내용을 익혔습니다.

- C++ 기본 문법과 함수 구조 이해
- 배열과 조건문을 활용한 간단한 로직 구현
- Windows API를 이용한 GUI 프로그램 설계
- Python에서 시각적 인터페이스와 3D 객체를 다루는 기초 이해
