SCAMPER(스캠퍼)는 창의적인 아이디어를 짜내거나 기존의 제품·서비스를 개선할 때 사용하는 대표적인 브레인스토밍 기법(아이디어 발상법)입니다.
미국의 교육학자 밥 에벌(Bob Eberle)이 고안한 것으로, 기존의 것을 7가지 서로 다른 관점에서 질문을 던지며 뒤틀어보고 변형해 보면서 새로운 아이디어를 유도하는 체크리스트 기법입니다.
'SCAMPER'라는 단어 자체가 아래 7가지 핵심 질문의 앞 글자를 딴 줄임말입니다.

💡 SCAMPER의 7가지 규칙과 예시
1. Substitute (대체하기)
"A 대신 B를 쓰면 어떨까?"
구성 요소, 재료, 사람, 장소 등을 다른 것으로 바꾸는 생각입니다.
예시: 종이 가방 대신 플라스틱이 없는 친환경 친수성 전분 가방 사용, 목재 가구 대신 가볍고 튼튼한 탄소 섬유 사용.
2. Combine (결합하기)
"A와 B를 하나로 합치면 어떨까?"
서로 다른 두 가지 이상의 기능이나 제품, 아이디어를 융합하는 생각입니다.
예시: 휴대폰 + 카메라 + MP3 플레이어 = 스마트폰, 샴푸 + 린스 = 투인원(2-in-1) 샴푸.
3. Adapt (적용하기/수용하기)
"다른 분야의 원리나 아이디어를 이 제품에 가져오면 어떨까?"
이미 성공한 외부의 아이디어나 자연의 원리를 내 문제에 맞게 벤치마킹하는 생각입니다.
예시: 상어 피부의 미세한 돌기 원리를 적용한 전신 수영복, 찍찍이 식물의 갈고리를 본뜬 벨크로(테이프).
4. Modify / Magnify / Minify (변형·확대·축소하기)
"모양, 색깔을 바꾸거나 엄청 크게/작게 만들면 어떨까?"
크기나 형태, 색상, 무게 등을 극단적으로 조절하거나 특성을 바꾸는 생각입니다.
예시 (Magnify): 화면을 극대화한 IMAX 영화관
예시 (Minify): 컴퓨터를 손목 위에 올릴 만큼 축소한 스마트워치
5. Put to other uses (다른 용도로 사용하기)
"이것을 완전히 다른 목적으로 쓸 순 없을까?"
원래 제품의 목적 외에 새로운 시장이나 용도를 찾아내는 생각입니다.
예시: 강력 접착제를 만들려다 실패해 접착력이 약해진 물질을 메모지로 활용한 포스트잇, 군사 작전용 위치 추적 기술을 민간에 개방한 GPS 네비게이션.
6. Eliminate (제거하기)
"이 기능을 아예 없애버리면 어떨까?"
당연하게 있던 부품, 기능, 단계 등을 과감히 생략하여 단순화하는 생각입니다.
예시: 이어폰 구멍을 없앤 무선 이어폰, 계산원과 카운터를 없앤 무인 마트.
7. Reverse / Rearrange (역발상·재배치하기)
"순서를 바꾸거나 위아래, 안과 밖을 뒤집으면 어떨까?"
기존의 형식이나 순서를 반대로 뒤집거나 구조를 재구성하는 생각입니다.
예시 (Reverse): 케첩이 잘 안 나오는 불편함을 해결하기 위해 거꾸로 세워두게 만든 짜먹는 케첩 튜브, 손님이 주방에 와서 음식을 받아 가는 패스트푸드점 셀프서비스.
🛠️ SCAMPER는 언제 쓰나요?
아무것도 없는 맨땅에서 아이디어를 짜내기 막막할 때.
기존에 잘 팔리던 우리 회사 제품의 '시즌 2' 업그레이드 버전을 개발해야 할 때.
문제 해결 과정에서 고정관념에 갇혀 진전이 없을 때.
질문 리스트(S-C-A-M-P-E-R)를 쭉 띄워놓고 하나씩 대입하다 보면, 뇌가 강제로 다양한 방향으로 자극을 받아 신선한 아이디어를 빠르게 도출해 낼 수 있습니다.
